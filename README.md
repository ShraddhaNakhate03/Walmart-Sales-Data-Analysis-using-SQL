# 🛒 Walmart Sales Data Analysis using SQL

## 📌 Project Overview
This project analyzes Walmart sales data to extract meaningful business insights using SQL. It focuses on understanding customer behavior, sales trends, and overall business performance across branches, categories, and payment methods.

---

## 🎯 Objectives
- Analyze sales transactions across multiple branches  
- Identify customer purchasing patterns  
- Evaluate product category performance  
- Track revenue and profit trends  
- Generate actionable business insights  

---

## 📊 Dataset Description
The dataset includes transaction-level sales data with the following fields:

- Branch  
- City  
- Category  
- Payment Method  
- Quantity  
- Unit Price  
- Total Sales  
- Rating  
- Date & Time  

---

## 🔍 Business Problems Solved

### 1. Payment Analysis
- Count transactions by payment method  
- Calculate total quantity sold per payment type  

### 2. Category Performance
- Identify highest-rated category in each branch  

### 3. Sales Trends
- Determine busiest day for each branch  

### 4. Inventory Insights
- Analyze total quantity sold  

### 5. Customer Experience
- Calculate min, max, and average ratings by category and city  

### 6. Profit Analysis
- Compute total profit:
  Profit = Unit Price × Quantity × Profit Margin  

### 7. Payment Preferences
- Find most common payment method per branch  

### 8. Time-Based Analysis
- Categorize sales into Morning, Afternoon, Evening  

### 9. Revenue Analysis
- Identify branches with highest revenue decline year-over-year  

---

## 🛠️ SQL Concepts Used
- Aggregate Functions (SUM, AVG, COUNT, MIN, MAX)  
- Window Functions (RANK)  
- Common Table Expressions (CTEs)  
- CASE WHEN Conditions  
- Date Functions (YEAR, DAYNAME)  
- GROUP BY & ORDER BY
